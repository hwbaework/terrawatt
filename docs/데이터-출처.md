# TerraWatt v0.3 — 데이터 출처표

화면에 나오는 모든 숫자가 어디서 왔는지 정리한 표. (교육자료·시연 질의응답용)

화면에는 출처를 적지 않는다 — 화면은 깨끗하게, 근거는 이 문서로.

## 실제로 연동되어 있는 것

| 항목 | 화면 | 출처 | 갱신 |
|---|---|---|---|
| 3D 지도·지형·주변 건물 | 배경 전체 | 국토교통부 브이월드 (공간정보 오픈플랫폼) | 브이월드 제공 주기 |
| 일사량 (발전량 시뮬레이션) | 발전량 시뮬 | NASA POWER 위성 관측 — 2025년 울산 지점 실측 | 시뮬 실행 시마다 실시간 호출 |
| 한일튜브 3D 모델 | 지도 위 건물 | 사내 실측 모델 (서현진 과장, 78.8×22×126.4m) | 고정 |
| 시설 위치 | 지도 | 울산 남구 부곡동 273-6 — Plus Code·위성사진 대조로 확정 | 고정 |

## 아직 공급원이 없는 것 (화면 항목만 존재)

| 항목 | 필요한 것 |
|---|---|
| 과열 감시 | LASEE에 인버터 온도 필드 존재 여부 확인 (없으면 센서) |
| 연기 감지·화재징후 | 감지 센서 설치 |
| 장애처리 절차 (DiSOP) | 플랫폼 측 하반기 개발 후 연동 |
| 재해 시뮬 (지진·홍수·태풍) | 인천 개발물 도입 예정 — 자체 개발 아님 |
